# Agentic Call: mobile app

React Native + Expo Router app for the agents: watch AI calls live, take over handoffs, place and schedule AI calls,
keep contacts and see insights. The backend is in `../backend` (see the main README).

## Run it

```powershell
npm install
copy .env.example .env      # then fill in the server URL and Firebase values
npx expo start              # live reload on a phone/emulator that has the debug build installed
```

## Checks

| Command | What it does |
|---|---|
| `npm test` | unit tests in `__tests__/` (Jest) |
| `npm run typecheck` | TypeScript |
| `npm run lint` | ESLint (`eslint.config.js`) |
| `npm run format` | Prettier (`.prettierrc.js`) |

## Build the Android APK

Windows' path-length limit breaks the native build in this folder, so it runs from the short-path copy
`C:\agentic-build` (`android/` here is a link to `C:\agentic-build\android`).

```powershell
robocopy "C:\Users\ABC\Documents\agentic app\frontend\src" C:\agentic-build\src /MIR
Copy-Item .env C:\agentic-build\.env -Force
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio1\jbr"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
cd C:\agentic-build\android
.\gradlew.bat :app:createBundleReleaseJsAndAssets --rerun assembleRelease "-PreactNativeArchitectures=x86_64,arm64-v8a"
```

The APK lands in `C:\agentic-build\android\app\build\outputs\apk\release\app-release.apk`.
Don't run `gradlew clean` (it fails on the generated native code): delete `android\app\.cxx` and `android\app\build` instead.

## iOS

`ios/` is generated (it can only be built on a Mac with Xcode, or in the cloud with `npx eas build -p ios`).
On a Mac: `bundle install`, then `cd ios && bundle exec pod install`, then open `ios/AgenticCall.xcworkspace`.

## Files and folders

| Path | What it is |
|---|---|
| `src/app/` | screens; the folder layout is the navigation (Expo Router) |
| `src/features/` | one folder per feature: API calls, stores, components |
| `src/components/`, `src/services/`, `src/state/`, `src/theme/`, `src/utils/` | shared UI, server/socket/auth clients, live store, colours, helpers |
| `__tests__/` | unit tests |
| `assets/` | app icon, splash and images |
| `android/`, `ios/` | native projects (generated by `npx expo prebuild`) |
| `app.config.ts` | app name, ids, version, plugins (Expo's version of `app.json`) |
| `babel.config.js`, `metro.config.js` | how the code is compiled and bundled |
| `jest.config.js`, `jest.setup.js` | test setup |
| `eslint.config.js`, `.prettierrc.js`, `.editorconfig` | code style |
| `eas.json` | cloud build profiles (Expo EAS) |
| `Gemfile`, `.bundle/` | Ruby/CocoaPods versions for the iOS build |
| `.env` / `.env.example` | server URL and Firebase ids (only `EXPO_PUBLIC_*`, baked into the build) |
| `.nvmrc`, `.watchmanconfig` | Node version, file-watcher settings |
